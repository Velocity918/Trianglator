How to use

The Edge Detection Thresholds control which edges are detected in the image. The lower threshold controls weak edges, while the higher threshold controls strong edges.

The SIFT parameter controls the maximum number of important points detected by SIFT. A value of 0 allows all detected points to be used.

The Density of Background Points controls how frequently points are placed in areas without detected features. A higher value creates more points and therefore smaller triangles.

Processing may take at least 20 seconds.
